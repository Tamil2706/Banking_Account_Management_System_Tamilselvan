# 🏦 Bank Account Management System

A C++ console-based banking application developed using Object-Oriented Programming (OOP) principles. The system allows users to create and manage bank accounts, perform transactions, transfer funds, calculate interest, and maintain transaction history through a menu-driven interface.

---

## 🎯 What It Does

### Account Management
- Create and manage Savings accounts.
- Create and manage Current accounts.

### Banking Operations
- Deposit money.
- Withdraw money.
- Transfer funds between accounts.
- Check account balances.

### Transaction History
- Track all account transactions.

### Interest & Overdraft
- Calculate interest for Savings accounts.
- Provide overdraft facility for Current accounts.

### Menu-Driven Interface
- Easy-to-use console application with input validation.

## 🚀 Getting Started

### Prerequisites

- C++17 compatible compiler
- Visual Studio Code / CodeBlocks / g++

### Installation

1. Clone the repository.
2. Open the project in your preferred IDE.
3. Compile using a C++17 compatible compiler.
4. Run the executable.
